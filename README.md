# خزف كافيه — نظام الكاشير والمخزون

كاشير مقهى بسيط للواجهة، متين في الخلفية: يمنع السرقة عبر دفتر مخزون غير قابل
للتعديل، دفع ذرّي، عدّ درج أعمى، وصلاحيات مفروضة في الخادم. الأرقام إنجليزية،
والفلوس بالدينار العراقي بلا كسور. **مشروع منفصل تماماً عن موقع خزف.**

المواصفة المرجعية: `docs/CAFE-POS-TECH.md`. القرارات: `docs/DECISIONS.md`.

## التقنية
- Next.js 14 (App Router) · React 18 · TypeScript · Tailwind.
- Neon Postgres 17 — الوصول من الخادم فقط برابط سرّي (لا واجهة عامة، لا مفتاح مجهول).
- منطق المال والمخزون في **دوال قاعدة** ذرّية (`db/migrations`).

## التشغيل محلياً
```bash
npm install
cp .env.example .env.local   # واملأ القيم
npm run dev
```

## المتغيّرات (`.env.local`)
| المتغيّر | الوصف |
|---|---|
| `DATABASE_URL` | رابط Neon (سرّي، بلا `NEXT_PUBLIC_`) |
| `SESSION_SECRET` | سرّ توقيع الجلسة — ولّده: `node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"` |

## قاعدة البيانات
طبّق بالترتيب (تفاصيل في `db/README.md`):
1. `db/migrations/0001_schema.sql` — المخطّط (٢٤ جدولاً).
2. `db/migrations/0002_auth.sql` — قفل محاولات PIN.
3. `db/migrations/0003_checkout.sql` — دالة الدفع الذرّي.
4. `db/migrations/0004_inventory.sql` — دوال الشراء/الهدر/الجرد.
5. `db/seed.sql` — بيانات أوّلية.

## النشر (Vercel)
1. اربط المستودع بمشروع Vercel.
2. أضف `DATABASE_URL` و`SESSION_SECRET` في إعدادات البيئة.
3. طبّق الهجرات والبذور على قاعدة Neon (مرّة واحدة).
4. انشر. (بيئة التطوير هنا لا تصل Neon بسبب حجب الشبكة — الاختبار الحيّ بعد النشر.)

**الطابعة الحرارية:** الفاتورة تُطبع من المتصفح (٨٠مم). عند الشراء اجعلها الافتراضية
وفعّل الطباعة الصامتة (Chrome: `--kiosk-printing`) لتخرج بلا نافذة تأكيد.

## مبادئ معمارية (لا تُكسَر)
- **الرصيد = Σ(inventory_transactions)**؛ `cached_stock` تسريع يتغيّر فقط بحركة.
- **الدفع ذرّي**: طلب + مخزون + كاش في معاملة واحدة، مع منع تكرار (`idempotency_key`)
  وقفل صفوف يمنع المخزون السالب. رقم الطلب بعد التحقّق → بلا فجوات.
- **الأسعار تُحسب في القاعدة** لا من المتصفح.
- **الصلاحيات تُفحص في الخادم** لكل عملية (لا يكفي إخفاء الزر ولا فحص الـlayout —
  الـServer Actions تُنادى بطلب مباشر).
- **لا حذف** للعمليات المالية/المخزنية — التصحيح بعملية عكسية.
- عدّ الدرج والجرد **أعميان** (كشف النقص). `src/lib/db.ts` معلَّم `server-only`.
