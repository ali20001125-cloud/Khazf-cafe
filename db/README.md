# قاعدة البيانات — خزف كافيه

المرجع الكامل للمخطّط: `docs/CAFE-POS-TECH.md`.

## الملفات
- `migrations/0001_schema.sql` — المخطّط المعتمد (٢٤ جدولاً، أنواع، فهارس، قيود).
- `seed.sql` — بيانات أوّلية قابلة للتعديل من اللوحة (عمل/فرع/أدوار/مستخدمَين/مواد/
  مشروبات/محاصيل/وصفات/إعدادات + رصيد افتتاحي عبر الدفتر).

## ترتيب التطبيق
1. `0001_schema.sql`  (يبدأ بإسقاط نظيف — آمن لإعادة التطبيق على قاعدة تطوير).
2. `seed.sql`.

## كيف تُطبَّق
- **من بيئة التطوير هنا:** أدوات Neon (`run_sql_transaction`) عبر HTTP API — لأن
  اتصال Postgres الخام (منفذ 5432) محجوب ببروكسي البيئة.
- **محلياً بجهازك:** `psql "$DATABASE_URL" -f db/migrations/0001_schema.sql`
  ثم `psql "$DATABASE_URL" -f db/seed.sql`.

## مبادئ لا تُكسَر
- الرصيد الحقيقي للمخزون = `Σ(inventory_transactions.qty_delta)`.
  `materials.cached_stock` تسريع فقط، لا يُعدَّل يدوياً — يتغيّر فقط بإدراج حركة.
- الفلوس والكميات أعداد صحيحة.
- لا حذف للعمليات المالية/المخزنية — التصحيح بعملية عكسية.
